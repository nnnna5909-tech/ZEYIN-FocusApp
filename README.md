# ZEYIN - Focus, AI Planner & Rewards

**ZEYIN** — пайдаланушыларға зейінін шоғырландыруға, оқу немесе жұмыс процестерін жоспарлауға және өнімді уақытты брендтердің сыйлықтарына/жеңілдіктеріне айырбастауға мүмкіндік беретін цифрлық платформа

---

## Негізгі мүмкіндіктер (Features)
- **Фокус сессиялары (Gamified Focus):** Өнімді уақытты геймификация арқылы виртуалды ұпайларға айналдыру
- **AI Планер:** Оқу немесе жұмыс тапсырмаларын автоматты түрде кішігірім қадамдарға бөліп беретін ақылды көмекші.
- **Сыйлықтар мен Ұсыныстар:** Пайдаланушының қызығушылығына сай бейімделген бренд бонустары мен жеңілдіктер

## Қолданылған технологиялар (Tech Stack)
- **Frontend:** HTML, CSS, JavaScript
- **Авторизация:** Google, GitHub, Facebook
- **Хостинг:** Netlify
